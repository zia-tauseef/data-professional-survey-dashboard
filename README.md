# Data Professional Survey Dashboard

An interactive Power BI dashboard analysing a survey of 630 data professionals.

![Dashboard preview](images/dashboard-preview.png)

## About the project
This dashboard explores who works in data, what they earn, which languages
they use, and how happy they are in their jobs. I built it while following
the Power BI course by Alex the Analyst, as part of learning data analysis.

## Key insights
- 630 survey respondents, average age 29.87
- Most respondents are from the United States, followed by India
- Python is the most popular programming language
- Data Scientists have the highest average salary
- Average happiness: 4.27/10 with salary, 5.74/10 with work-life balance
- Most people found breaking into data neither easy nor difficult

## Tools used
- Power BI Desktop
- DAX (measures such as average age and survey count)

## Requirements
- Power BI Desktop (free, Windows only) to open the `.pbix` file
- Dataset is included in the `data/` folder

## How to use
1. Download this repository
2. Open `dashboard/Data_Professional_Survey_Breakdown.pbix` in Power BI Desktop
3. Explore the visuals and filter by clicking on charts
